⚠️ [사내 정책] Microsoft Edge가 구형 Internet Explorer(IE) 모드로 실행되었습니다
현재 주소(localhost)는 사내 보안/인트라넷 정책으로 인해 구형 IE 모드로 강제 전환되어 최신 UI 스타일(CSS) 및 화면이 차단된 상태입니다.
👉 해결 방법 1 (즉시 해결 - 강력 추천): http://127.0.0.1:8080/ 링크를 클릭하세요 (사내 IE 모드 자동 우회)
* '127.0.0.1'은 마침표(.)가 포함된 IP 주소이므로 사내 Edge의 '인트라넷 IE 모드 전송 정책'을 우회하여 최신 Edge(Chromium) 엔진으로 정상 표시됩니다.
👉 해결 방법 2: Edge 주소창 좌측의 파란색 [Internet Explorer] 아이콘 클릭 ➔ [Microsoft Edge에서 열기] 클릭
